## Using These with the DALL-E API

```python
import openai

client = openai.OpenAI()

response = client.images.generate(
    model="dall-e-3",
    prompt="[paste prompt here]",
    size="1024x1792",
    quality="standard",  # change to "hd" for final render
    style="natural",
    n=1,
)

image_url = response.data[0].url
```
